# AI·Ранг — рейтинг нейросетей под вашу задачу

Статический сайт без сборки (чистый HTML/CSS/ES-модули). Показывает рейтинг моделей по данным
[aiiq.org](https://aiiq.org) и сверяет его ещё с пятью независимыми источниками.

## Что умеет
- **Сценарии**: универсал, программирование, агенты, наука, «дёшево и умно», быстро, длинные документы, открытые веса.
- **Свои веса**: 11 ползунков, рейтинг пересчитывается мгновенно.
- **Фильтры**: компании, только открытые веса, лимит цены, поиск (клавиша `/`).
- **График цена ↔ качество** с границей лучших вариантов (Парето); оси: цена, скорость, контекст.
- **Карточка модели**: профиль способностей, автоматические плюсы и минусы (только из чисел).
- **Сравнение** до 4 моделей: радар и таблица.
- **Консенсус** 6 источников: AI IQ, LMArena, SWE-bench, HF Open LLM, LiveBench, Aider.
- Любой вид рейтинга хранится в адресе (`#…`) — его можно отправить ссылкой. Тёмная и светлая темы.

## Как считается балл
1. Измерения IQ переводятся в 0–100 линейно (от 5-го перцентиля до максимума).
2. Цена, скорость, контекст — по перцентилю (у них огромные выбросы).
3. Сводный балл — взвешенное среднее. Нет данных по критерию → 30 из 100 и значок «≈».

## Структура
| Путь | Назначение |
|---|---|
| `index.html`, `css/style.css` | страница и дизайн |
| `js/score.js` | критерии, сценарии, подсчёт, плюсы/минусы (чистая логика, есть тесты) |
| `js/normalize.js` | приведение названий моделей к одному ключу (браузер и Node) |
| `js/data.js` | загрузка данных, консенсус |
| `js/charts.js` | SVG-графики без библиотек |
| `js/ui.js`, `js/main.js`, `js/state.js` | интерфейс, события, состояние в URL |
| `js/config.js` | **настройки владельца**, в том числе реферальные коды |
| `scripts/build-sources.mjs` | сборщик данных из 6 источников |
| `data/aiiq.json`, `data/sources.json` | данные (обновляет бот) |

## Данные и автообновление
- aiiq.org запрашивается из браузера при открытии; если API недоступен — берётся `data/aiiq.json`.
- GitHub Actions (`.github/workflows/update-sources.yml`) раз в 6 часов запускает `node scripts/build-sources.mjs`.
  Если источник не ответил, остаётся его прошлая версия с пометкой «данные не обновились».
- Локально: `npm run build:data`, тесты: `npm test`, просмотр: `python3 -m http.server`.

## Реферальные ссылки
Впишите свой код в `js/config.js` → `REF_DEFAULTS` и закоммитьте — тогда он работает у всех посетителей.
Для себя можно задать коды в панели «Мои реф-коды» на сайте (хранятся в браузере) или в адресе: `?ref_openrouter=КОД`.
